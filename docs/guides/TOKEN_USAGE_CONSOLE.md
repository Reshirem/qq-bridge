# 令牌与花费

打开 WebUI → 令牌与花费，可以查看各功能的输入、缓存读写、输出和费用。点击功能名称会显示该功能最近的轮次。消耗走势可以切换美元、旧账本币种和 token。

| 功能 | 记录来源 |
| --- | --- |
| 主会话 | 全局数字角色的 DSH 事件。QQ 群聊、私聊和 WebUI 对话共用这个会话。重连时合并 DSH 的累计用量和最近的逐次记录。 |
| 记忆整理 | 独立整理会话的 DSH 记录。每次运行结束后同步，启动时补读仍可访问的整理会话。中途失败的任务也保留已经上报的用量。 |
| 后台学习 | 黑话与表情学习批次共用同一次推理，按 DSH 上报用量的步骤记账。升级前保留下来的累计输入和输出也计入该功能。 |
| 其他历史 | 旧账中无法确定来源的会话。 |

## 价格

桥接从 [models.dev 目录](https://models.dev/api.json) 下载每百万 token 的美元单价，按实际服务商和模型 ID 匹配。相同模型在不同服务商的价格独立。若目录公布了长上下文档位，按单次调用的输入总长度选择对应单价。缓存没有独立单价时使用同一档输入价，推理输出没有独立单价时使用输出价。订阅、配额和账户折扣可能使实际扣款与目录估算不同。

目录缓存放在 `state/models-dev-prices.json`。首次启动会获取目录，通常每 24 小时更新一次。有模型缺价时最多每小时自动重查一次，也可以点击「刷新模型价格」。获取失败时保留最后一次成功下载的目录。

有明细的调用首次匹配价格后，账本会同时保存采用的单价和金额。以后的刷新只补记尚未定价的调用。目录明确给出的零价可以直接入账。只有累计用量、无法确认逐次模型和上下文长度的历史，继续显示为未计价 token。图表只覆盖有时间戳的明细。

## 旧账迁移

新账本在 `state/token-usage.sqlite`。首次启动会合并旧 JSONL 的投影基线、逐次调用和已压缩汇总，按升级前的配置冻结旧版显示的费用。旧账原币种和新增美元费用分列显示。桥接保留 `state/token-usage.jsonl` 原文件。迁移标记与数据在同一事务提交，重启或清空账本后不会重复导入这份文件。

用量与价格接口沿用控制台登录权限。价格下载只请求公共目录。
