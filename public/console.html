这是唯一的长期 DSH 会话。尚未创建时，启动自主探索或发送任务会自动创建它。点“启动自主探索”即可开始自主活动并选择关注点；也可以输入明确任务。电脑、QQ 和其他已开放工具都可按需使用，QQ 只是消息渠道之一。

每个回合结束前，陪伴者应调用 agent_rest 并自行选择休息时长；直接在 DSH 对话中发消息、提交 WebUI 任务或收到有效 QQ 提醒，都可提前结束休息并唤醒一轮，休息期间异常回合的指数恢复重试暂停。未正常休息的回合会按指数间隔尝试恢复，最长间隔 30 分钟。“停止自主运行”会取消当前及排队任务并持久停止自动唤醒；再次从此页面启动或提交任务即可恢复。不会发送周期性模型心跳。快捷键 Ctrl + Enter 可发送具体任务。QQ 私聊、原生 @、已验证回复/引用和关键词只是提醒，是否读取或回复由陪伴者自己决定。

A_Memorix 连接与模型服务

连接设置控制桥接如何访问共享记忆库以及首次会话摘要的大小。Embedding 和 LLM Provider 由 A_Memorix 用于语义检索与记忆整理；配置后，记忆内容会发送到所填服务并可能产生费用。

桥接连接与启动摘要

Gateway 只允许本机回环地址；namespace 必须已在 A_Memorix 中创建。密钥不会从服务端回显，留空表示保留已保存的密钥。

A_Memorix 模型服务（Embedding / LLM）

Embedding 用于语义检索；LLM 用于记忆关系、画像和情景整理。外部地址必须使用 HTTPS。密钥只写入本机受保护的 state 目录，页面不会回读。

⚠️ state/ 目录权限未收紧
Windows 上改文件权限需要管理员身份，本次启动没能收紧 。它里面的控制台令牌、SnowLuma 令牌、全局陪伴者令牌与 QQ 消息缓存，本机任何已登录用户都可能读到。
两种做法：① 用管理员身份打开终端执行下面这条命令（一次即可，可复制）；② 或者用管理员身份重启桥接，让它自己收紧。做完点下面的按钮复检。

        
        
      

      

        ⚠️ QQ 网关连着，但收不到 QQ 的数据
        

        
最近一个上游事件包：unknown；SnowLuma 自评接收链路 good=unknown。

        
这是 SnowLuma 自己那边的问题：它的 [Hook] 没能从 QQ 客户端取到数据，所以桥接的 WebSocket 连上了却始终没有内容可收。桥接没有原生 / 注入组件，也不改 SnowLuma，一条上游事件包都不会替你凭空造出来。

        
排查：打开 SnowLuma 的 logs/snowluma-*.log，搜 [Hook]，看有没有 receive path stale / process enumeration timed out 这类行；顺带考虑升级 SnowLuma（新版运行时对 hook 的兜底更好）。桥接这边不用重启。
