人格卡模板用于格式化每次放入 DSH persona 固定前缀的当前卡片；切换或编辑后下一次模型请求生效。QQ 提醒和恢复说明按后续事件附加到会话消息中，记忆摘要只在新会话开场时附加。保存模板后立即更新桥接运行配置。

占位符：{roleName} 人格名（可省略），{roleContent} 人格卡正文（必须保留）。
占位符：{sources} 提醒来源列表（必须保留）；模板不包含 QQ 消息正文。
占位符：{key} 会话标识、{kind} 私聊/群聊、{reason} 提醒原因、{sender} 发送者、{senderId} 发送者 QQ、{messageId} 消息定位（id:QQ消息ID 或 seq:本地序号@缓存标识）、{count} 合并数量。{key} 必须保留；后三项无对应信息时为空，并自带前置标点。
休息到期、QQ 打断和异常恢复提示都可以留空。
占位符：{entries} 已检索到的自身经历摘要（必须保留）。

A_Memorix 连接与模型服务

连接设置控制桥接如何访问共享记忆库以及首次会话摘要的大小。Embedding 和 LLM Provider 由 A_Memorix 用于语义检索与记忆整理；配置后，记忆内容会发送到所填服务并可能产生费用。

桥接连接与启动摘要

Gateway 只允许本机回环地址；namespace 必须已在 A_Memorix 中创建。密钥不会从服务端回显，留空表示保留已保存的密钥。

A_Memorix 模型服务（Embedding / LLM）

Embedding 用于语义检索；LLM 用于记忆关系、画像和情景整理。外部地址必须使用 HTTPS。密钥只写入本机受保护的 state 目录，页面不会回读。

提醒规则

私聊、原生 @、回复角色、提到当前人格卡名称或命中下方关键词时，角色会收到消息位置。普通休息可被提醒打断。睡眠时只缓存消息，起床后只接收新的提醒。

所有群聊共用。每项 2–64 个字符，最多 50 项。

分条发送与未读

模型决定发几条。第一条直接发送，后续每条按该条字数计时，最多等 1000 ms。设为 0 可连续发送。

每个群和私聊最多保留 500 条未读，满后新来信会替换最早一条。角色查看未读、聊天历史或单条详情时，只扣除本次读到的来信。
