# 角色卡（人格）

每个角色使用一个 Markdown 文件，文件名就是角色名。控制台「人格与角色」页负责选择启用。当前选中的角色卡只注入**唯一的全局 `desktop-agent` DSH 会话**；QQ 群或私聊不会创建单独的 DSH 会话。

## 人格卡写什么

人格卡决定具体身份、形态、性格、兴趣、说话风格、关系和边界，可以是人类或非人设定。桥接在全局 DSH 会话第一次收到任务或提醒时注入所选卡片一次，后续回合由会话上下文延续，不再重复附加。全局会话的自主活动方式、电脑操作边界以及 QQ 消息读取和发送方式，由 [desktop-agent preset](../dsh/agent-presets/desktop-agent/agent.cordis.yml) 规定。人格卡不会自行生成任务，也不应复制工具调用流程。

## 字符上限与编辑

- 首次注入最多 8000 字符，由 `config.json` 的 `role.maxInjectChars` 配置，可设为 1000 到 20000；控制台也可修改。
- 全局会话首次收到任务或提醒时加载当时选择的人格卡。已有会话不会在后续回合重复加载，也不会因编辑/切换而改写已开始的上下文；新建或重建全局会话后，首次提示会加载新卡片。
- 建议保持在 3000 到 5000 字符，避免首次上下文过长。
- 人格卡按 Markdown 正文整体注入；普通标题和小节都只是内容组织方式，不会切换运行模式。
- 想让下一次新建或重建的会话不带人格卡，在控制台清除当前角色；已有会话中已注入的卡片仍保留在历史上下文。

推荐内容结构：

```markdown
# 角色卡：<角色名>

## 你是谁
- 身份、自我认知、称呼和边界。

## 说话风格
- 句子长短、口头禅、标点习惯。

## 性格与反应
- 被夸、被怼、被无视时通常如何反应。

## 背景与关系（可选）
- 来历、关系、常用梗及其边界。

## 回复示例（可选）
- 示例只展示语气与长度，不写工具流程。
```
