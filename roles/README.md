# 角色卡（人格）

每个人格卡使用一个 Markdown 文件，文件名就是卡名。控制台「人格与角色」页负责选择启用。当前选中的人格卡只用于**唯一的全局 `desktop-agent` DSH 会话**；QQ 群或私聊不会创建单独的 DSH 会话。

## 人格卡写什么

人格卡决定具体身份、形态、性格、兴趣、说话风格、关系和边界，可以是人类或非人设定。`qq-agent-presets` 通过 DSH persona 前缀变量在**每次提示词组装时**读取当前卡片；因此人格卡不会被普通会话历史压缩掉。切换、编辑、清除、改名或删除后，下一次模型请求会用新的选择和正文。全局会话的自主活动方式、电脑操作边界以及 QQ 消息读取和发送方式，由 [desktop-agent preset](../dsh/agent-presets/desktop-agent/agent.cordis.yml) 规定。人格卡不会自行生成任务，也不应复制工具调用流程。

## 长度建议与编辑

- 建议人格卡控制在 6000 字符以内；以中文为主时约占 3600 tokens。超过建议长度只会提示，仍完整保存并放入 persona 固定前缀，不会截断。
- 人格卡处于 DSH `persona.prefix`，会随每次模型请求进入 system prompt，并占用相应上下文 token；它不会在每条 QQ 提醒消息里重复，也不依赖重建会话来更新。
- 首次安装带有 `qq_bridge_active_role_card` 变量的新版 DSH preset / 插件时，需要重启 DSH 并重建全局会话加载新版固定前缀。之后只需保存当前卡片或切换选择，下一次模型请求自动载入新状态。
- 控制台编辑区和已保存的人格卡列表都会显示字符数与 token 估算；粗估参考 [DeepSeek 官方换算说明](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)，实际用量以模型返回为准。
- 人格卡按 Markdown 正文整体载入；普通标题和小节都只是内容组织方式，不会切换运行模式。
- 想让后续模型请求不带人格卡，在控制台清除当前选择；下一次提示词组装时变量为空，固定前缀中的通用陪伴者定位继续生效。

推荐内容结构：

```markdown
# 角色卡：<角色名>

## 你是谁
- 身份、自我认知、称呼和边界。

## 说话风格
- 句子长短、口头禅、标点习惯。

## 性格与反应
- 被夸、被怼、被无视时通常如何反应。

## 背景与关系（可选）
- 来历、关系、常用梗及其边界。

## 回复示例（可选）
- 示例只展示语气与长度，不写工具流程。
```
