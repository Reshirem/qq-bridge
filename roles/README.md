# 角色卡（人格）

每个角色使用一个 Markdown 文件，文件名就是角色名。控制台「人格与角色」页负责选择启用。当前选中的角色卡只注入**唯一的全局 `desktop-agent` DSH 会话**；QQ 群或私聊不会创建单独的 DSH 会话。

## 人格卡写什么

人格卡只描述角色身份、性格、兴趣、说话风格、关系和边界。桥接在全局 DSH 会话第一次收到任务或提醒时注入所选卡片一次，后续回合由会话上下文延续，不再重复附加。桌面助手的工作方式、电脑操作边界以及 QQ 消息读取和发送方式，由 [desktop-agent preset](../dsh/agent-presets/desktop-agent/agent.cordis.yml) 规定。人格卡不会自行生成任务，也不应复制工具调用流程。

## 旧标题标签兼容

旧角色卡可以保留标题上的 `〔二代〕`、`[v2]`、`（reserved2）`、`〔2 代〕` 等标签，也可以保留 `v1` / `reserved` 标签。它们只用于选择兼容的人格小节，不代表还有多种运行模式或 QQ 会话 preset。当前 `desktop-agent` 固定注入未标记小节与 `v2` 小节；旧 `v1` 专属小节不注入。注入前会移除标题标签。

例如：

```markdown
## 说话风格 〔v2〕
- 句子简短，像平常聊天。

## 兴趣
- 喜欢研究鲸鱼。
```

两个小节都会注入当前全局助手；第二个小节没有兼容标签。

## 字符上限与编辑

- 首次注入最多 8000 字符，由 `config.json` 的 `role.maxInjectChars` 配置，可设为 1000 到 20000；控制台也可修改。
- 全局会话首次收到任务或提醒时加载当时选择的人格卡。已有会话不会在后续回合重复加载，也不会因编辑/切换而改写已开始的上下文；新建或重建全局会话后，首次提示会加载新卡片。
- 建议保持在 3000 到 5000 字符，避免首次上下文过长。
- 想让下一次新建或重建的会话不带人格卡，在控制台清除当前角色；已有会话中已注入的卡片仍保留在历史上下文。

推荐内容结构：

```markdown
# 角色卡：<角色名>

## 你是谁
- 身份、自我认知、称呼和边界。

## 说话风格
- 句子长短、口头禅、标点习惯。

## 性格与反应
- 被夸、被怼、被无视时通常如何反应。

## 背景与关系（可选）
- 来历、关系、常用梗及其边界。

## 回复示例（可选）
- 示例只展示语气与长度，不写工具流程。
```
